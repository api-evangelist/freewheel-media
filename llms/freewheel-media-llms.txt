# FreeWheel Media

> FreeWheel, a Comcast company, is an advertising technology platform for the streaming and premium video television marketplace, connecting advertisers, agencies, publishers, and programmers across linear and digital channels. FreeWheel publishes four API families on a ReadMe-hosted developer portal at api-docs.freewheel.tv — Advertiser (Buzz/Beeswax), Partner/Demand, Publisher (MRM) and Strata — all of them credential-gated: FreeWheel issues credentials to contracted partners and there is no self-service signup, no public pricing and no sandbox other than a Publisher staging host.

## APIs
- [FreeWheel Advertiser (Buzz) API](https://api-docs.freewheel.tv/advertiser): The Beeswax DSP buy-side object model — advertisers, campaigns, line items, creatives, targeting templates, bidding strategies, segments, reporting, users and roles. 153 operations across 59 resources. Base URL is per-customer: `https://<buzz_key>.api.beeswax.com/rest/`. Session-cookie auth via `POST /authenticate`.
- [FreeWheel Demand Deal Sync API](https://api-docs.freewheel.tv/demand/reference): Retrieve programmatic deals for a buyer seat and update buyer status. Base `https://api.freewheel.tv/demand/v1`.
- [FreeWheel Demand Creative Management API](https://api-docs.freewheel.tv/demand/reference): Create and update creatives and pre-ingest them against deals. Base `https://api.freewheel.tv/demand/v1`.
- [FreeWheel Demand Audience Management API](https://api-docs.freewheel.tv/demand/reference): Ad-industry categories, data providers, segment search and audience definitions. Base `https://api.freewheel.tv/demand`.
- [FreeWheel Publisher (MRM) API](https://api-docs.freewheel.tv/publisher): Sell-side advertiser/agency management, insertion orders, placements, forecasting and reporting. V3 is XML, V4 is JSON. Base `https://api.freewheel.tv/services/v4/services`, staging `https://api.stg.freewheel.tv/services/v4/services`. No machine-readable specification is published and the reference is disallowed in the docs robots.txt.

## Runtime semantics
- [Authentication](authentication/freewheel-media-authentication.yml): Three unrelated models — OAuth 2.0 password grant at `https://api.freewheel.tv/auth/token` (Demand + Publisher, 7-day bearer tokens, no scopes), a Buzz session cookie, and an `X-Freewheel-Ad-Industry` header on audience calls.
- [Conventions](conventions/freewheel-media-conventions.yml): No idempotency key anywhere. Three different pagination styles. The Buzz envelope returns HTTP 200 for partially-failed bulk writes.
- [Errors](errors/freewheel-media-problem-types.yml): No RFC 9457. Only 5 of 171 operations declare any non-2xx response.
- [Rate limits](rate-limits/freewheel-media-rate-limits.yml): 20 requests/second, 429 on exhaustion, no rate-limit response headers.
- [Lifecycle](lifecycle/freewheel-media-lifecycle.yml): No deprecation policy, no Sunset headers, no working status page.
- [Data model](data-model/freewheel-media-data-model.yml): Buy-side and demand-side object graphs, and the seam between them.
- [Conformance](conformance/freewheel-media-conformance.yml)
- [Sandbox](sandbox/freewheel-media-sandbox.yml): Publisher staging only.
- [Plans and pricing](plans/freewheel-media-plans-pricing.yml): None published; enterprise contract only.
- [Packages](packages/freewheel-media-packages.yml): No first-party API client library in any language.
- [Changelog](changelog/freewheel-media-changelog.yml): 25 typed entries, newest over four years old.
